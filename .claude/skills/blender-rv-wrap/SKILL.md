# Blender 房车车衣交付

给需要在 Blender 里交出一辆**可编辑**房车车衣的 agent。步骤通用，可重复执行。

某一辆车的色号、贴花文案、门窗布置和可直接粘贴的执行提示词**不写在本技能里**。本仓库的项目实例在 [`docs/opc/blender-rv-wrap/`](../../../docs/opc/blender-rv-wrap/README.md)。先读该目录的输入状态，再把其中的提示词原文交给执行者；不要把实例内容抄回本技能。

本技能是交付步骤，不是网页功能。不改应用代码，不改 GLB，不把效果图当成可裁切施工图。

## 0. 输入（同一次任务里齐）

1. **成品四视图**：涂装事实来源。
2. **实拍**：结构事实来源，尤其是双侧门窗。
3. **可选原 `.blend`**：已确认的几何与比例。

缺实拍或原文件时，不要猜造结构或毫米尺寸。四视图不能代替实拍决定开孔、壁板和门。没有原 `.blend` 时，不要把它当成已确认几何。

有原 `.blend` 时：先**另存副本**，只在副本上做。沿用已确认的几何与比例，不重做整车。

## 1. 事实来源

- 实拍与双侧门窗基准决定结构。
- 成品四视图决定涂装。
- 两侧不可默认镜像。每一侧单独对照该侧的实拍和四视图。
- 没有实测尺寸的部位标「待量」。不要从透视照片硬推毫米。

看图和项目提示词对不上的部位标「待确认」，不改写提示词去圆图。

## 2. 涂装与材质

- 涂装以四视图为准。
- 不贴到玻璃、灯、把手、密封条。
- 色带按四视图绕开轮拱和禁止区域。
- 文字和图标用独立可编辑矢量或透明贴花，不烘进底色。
- 十六进制色是预览起点，不是膜厂色号。

| 部位 | 做法 |
| --- | --- |
| 原漆 | Principled BSDF，粗糙度 0.28–0.35，Coat 约 0.20 |
| 车衣 | 半哑光，粗糙度 0.40–0.48，边缘干净，反光比原漆柔和，不做凸起胶条 |
| 车窗 | 有厚度的微灰玻璃，IOR 约 1.45，粗糙度 0.05–0.12，能隐约见座椅 |
| 橡胶窗封、胎壁 | 高粗糙度 |
| 灯罩 | 清透，不用平涂色块 |
| 镀铬 | 只用在真实镀铬件上 |

## 3. 渲染与交付

- 引擎用 Cycles。背景中性灰，大面积柔光。同一批图统一曝光与比例。
- 交一张四视图。
- 交左右前斜。
- 交左右车窗贴花特写。
- 用前斜验证色带未串入禁止区。
- 用两张正侧验证轮拱留白与侧面图形方向。
- 提交打包纹理、可重新打开的 `.blend`，高清 PNG，以及材质参数表。
- 从新文件重新打开并复渲，确认打包后的文件本身能出同一结果。
- 报告哪些据实拍还原，哪些只是视觉推定。
- 效果图不等于可直接裁切施工图。

## 4. 做完核对

- [ ] 输入缺口已写明；缺实拍或原文件时没有补造结构和毫米。
- [ ] 有原 `.blend` 时，工作文件是另存副本，整车几何没有重做。
- [ ] 两侧是分别对照的，不是默认镜像。
- [ ] 未实测部位标了「待量」。
- [ ] 文字和图标仍是独立矢量或透明贴花。
- [ ] 前斜与两张正侧完成了色带禁止区和轮拱留白、图形方向的核对。
- [ ] 新打开的文件复渲过。
- [ ] 报告分开写了实拍还原和视觉推定。
