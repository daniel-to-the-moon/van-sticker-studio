# V80 设计决策与交接边界

版本和取用方式见[档案索引](README.md)。本页区分跨版本规则、构图试验和实际 p9，不将设想登记为工程交付。

## 跨版本保留

- **左右门窗不可镜像。** 驾驶侧是两扇近等大的横窗，无生活舱中门；副驾侧有带窄竖窗的中门，门后两扇较小近方窗。保留实际窗、门缝、把手、轮拱、灯具和后视镜底座。对照实拍只核比例与位置；未复尺不推局部毫米值。
- **米黄不是纯白。** p9 预览色为暖米黄 `#E8C49A`、牛仔蓝 `#174769`、芥末黄 `#E2A024`，反白参考 `#FFF0D4`。这是屏幕色，不是膜厂色号。车盖和正面大面保留米黄；下沿芥末黄沿原保险杠轮廓收齐。核对任何绕角色带时，左右侧、正前及两侧前 45° 对照同一组灯缘与板缝；不为求连线把蓝色铺上车盖。
- **黑边分区，不把灯涂黑。** 驾驶室两侧窗外的黑色在门缝内衔接镜座，不遮玻璃；灯眉向侧面自然收尾。灯罩、镀铬灯杯、琥珀件和黑饰件分别检查，灯色预览不证明真实配光。亮银只给侧边帐罩和端盖，不给上方钣金；帐盒位置不得压住侧窗。
- **徽标各自独立。** World Citizen 的帽檐朝左、长发头像在左、圆润双行字在右；同款时只改色和等比尺寸。DANIEL 是另一枚拱章，上弧拼写 `TO THE MOON`，不能用 World Citizen 替代。反白指图形换暖白，底仍透明，不加黑色矩形。

- **B 版 2D**：额头用同款 World Citizen 黑色缩小构图，驾驶门反白，副驾门保留 DANIEL。档案记录这个设计选择，不覆盖其它试稿或修改 p9。
- **p9 3D**：[已交版本](https://github.com/daniel-to-the-moon/van-sticker-studio/issues/130) 是两扇驾驶室门用 DANIEL，World Citizen 只在额头，每侧两枚泪滴。精修项：中网端头应更接近扁平冲压围边；前角、灯体外轮廓、雾灯、下包围和牌照区还有差异。不给旧模型补造实际牌照。下一位编辑先核对文件哈希、留原文件，并报告左右前 45° 和灯具近景的改前/改后差异。
