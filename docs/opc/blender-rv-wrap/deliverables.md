# 交付物清单

这是 Blender 执行者交回的文件，不是本目录里的提示词。效果图只作看图，不能直接裁切施工；施工前还要核对实车曲面和门缝。

| # | 交付物 | 要求 |
| --- | --- | --- |
| 1 | 可重新打开的 `.blend` | 另存副本上的工作文件。纹理已打包。从新文件重新打开后仍能复渲。有原文件时，整车几何沿用确认过的比例，不重做。 |
| 2 | 四视图 PNG | 一张图内包含统一曝光和比例的正侧两侧、正前、正后。高清。 |
| 3 | 左右前斜 PNG | 各一张。其中至少一张用来证明蓝带没有窜到车盖。 |
| 4 | 左右车窗贴花特写 PNG | 各一张。文字和图标仍是独立矢量或透明贴花，能在文件里单独改。 |
| 5 | 关键材质参数表 | 原漆、车衣、玻璃、橡胶窗封、胎壁、灯罩、镀铬件的着色器、粗糙度、Coat、IOR。十六进制色标成预览起点，不写成膜厂色号。 |
| 6 | 还原与推定报告 | 哪些据实拍还原，哪些只是视觉推定。未实测部位列出「待量」。缺了的输入写明，不把空缺写成已测量。 |

参数表建议列：

| 部位 | 着色器 | 关键参数 | 备注 |
| --- | --- | --- | --- |
| 原漆 | Principled BSDF | 粗糙度 0.28–0.35；Coat 权重约 0.20 | 与车衣分开 |
| 车衣 | 半哑光膜 | 粗糙度 0.40–0.48 | 边缘干净；反光比原漆柔和；不是凸起胶条 |
| 车窗 | 有厚度的微灰玻璃 | IOR 约 1.45；粗糙度 0.05–0.12 | 能隐约看到座椅 |
| 橡胶窗封、胎壁 | 高粗糙度 | 不发亮 | |
| 灯罩 | 清透 | 不用平涂色块 | |
| 镀铬 | 只用于真实镀铬件 | | 尾架哑黑；脱困板保留橙色 |

预览起点（不是膜厂色号）：暖米黄 sRGB #E8C49A（高光下不能看成纯白），牛仔蓝 #174769，芥末黄 #E2A024。
