# 可粘贴提示词

下面围栏内是维护者原文。交给 Grok 3D / Blender 执行者时整段粘贴，不改约束、不改色号、不改门窗描述。

与参考图或实拍对不上的部位标「待确认」，不要改这段原文去圆图。

```text
请在 Blender 里交付一辆可编辑的大通 V80 C 型房车，做成附件中的暖米黄／牛仔蓝／芥末黄车衣。若有原 .blend，先另存副本，沿用确认过的几何和比例，不重做整车。实拍和双侧门窗基准决定结构，成品四视图决定涂装。没有实测尺寸的部位标注「待量」，不要从透视照片硬推毫米尺寸。

车身与门窗

- 驾驶侧：两扇同高、近等大的横窗，中间有实体壁板，无生活舱中门。副驾侧：带窄竖窗的中门，门后两扇更小的近方窗。两侧不可镜像。保留额头窗、雨棚、原灯具和尾架。
- 车盖和正脸保持暖米黄。牛仔蓝沿两侧翼子板顺接大灯外缘，不绕上正脸。芥末黄绕前杠和车尾，两侧曲线同高。线条从轮拱上方绕开，露出连续米黄边；副驾中门保留整面米黄。不要贴到玻璃、灯、把手和密封条上。
- 两侧驾驶舱窗后，各三道黑色泪滴速度纹，圆头靠车窗、尖尾朝车尾：驾驶侧图头朝左，尖尾向右；副驾侧图头朝右，尖尾向左。不保留棋盘格。驾驶门为暖白小剪影＋单行 World Citizen；额头用同款黑色小字标，单行居中。副驾门暖白拱形 TO THE MOON / DANIEL，无色底，字间两条细线夹小菱形。用独立可编辑矢量或透明贴花，不把文字烘进底色。

材质与渲染预期

- 车身暖米黄，参考 sRGB #E8C49A，不能在高光下看成纯白；牛仔蓝 #174769，芥末黄 #E2A024。这些是预览起点，不是膜厂色号。车漆用 Principled BSDF，粗糙度 0.28–0.35，Coat 权重约 0.20；车衣用半哑光膜，粗糙度 0.40–0.48，边缘干净、反光比原漆柔和，不做成凸起的胶条。
- 车窗用有厚度的微灰玻璃，IOR 约 1.45、粗糙度 0.05–0.12，能隐约看到座椅；黑色橡胶窗封和胎壁用高粗糙度，不发亮。前杠黑件保留塑料质感和横向格栅，灯罩清透，不能用平涂白块代替。格栅镀铬只在真实镀铬件上使用；尾架哑黑，脱困板保留橙色。
- 用 Cycles、中性灰背景、大面积柔光，控制额头与车盖高光。交付一张统一曝光和比例的四视图，再交付左右前斜视角以及左右车窗贴花特写。至少用一张前斜图验证蓝带没有窜到车盖，再用两张正侧验证轮拱留白与泪滴方向。
- 提交可重新打开的 .blend（打包纹理）、高清 PNG 与关键材质参数表。从新文件重新打开并复渲。报告哪些地方据实拍还原、哪些只是视觉推定。效果图不等于可直接裁切施工；施工前还要核对实车曲面和门缝。
```
