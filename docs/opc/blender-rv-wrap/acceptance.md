# 验收清单

勾选依据是 [prompt.md](prompt.md) 围栏内的维护者原文。本清单只帮助核对，不改写约束。原文与清单措辞不一致时，以原文为准。

通用步骤见 [`.claude/skills/blender-rv-wrap/SKILL.md`](../../../.claude/skills/blender-rv-wrap/SKILL.md)。开始勾选前先读 [README](README.md) 的输入状态。

## 输入

- [ ] 成品四视图、双侧实拍（尤其门窗）和可选原 `.blend` 是同一次任务一起交来的。
- [ ] 缺实拍时没有猜造结构或毫米尺寸，并已停下写明缺项。
- [ ] 没有原 `.blend` 时，没有把它当成已确认几何，也没有凭空补毫米。
- [ ] 有原 `.blend` 时，先另存了副本，沿用确认过的几何和比例，没有重做整车。
- [ ] 没有实测的部位标了「待量」，没有从透视照片硬推毫米。

## 车身与门窗

- [ ] 驾驶侧：两扇同高、近等大的横窗，中间有实体壁板，无生活舱中门。
- [ ] 副驾侧：带窄竖窗的中门，门后两扇更小的近方窗。两侧不是镜像。
- [ ] 保留额头窗、雨棚、原灯具和尾架。
- [ ] 车盖和正脸保持暖米黄。牛仔蓝沿两侧翼子板顺接大灯外缘，不绕上正脸。
- [ ] 芥末黄绕前杠和车尾，两侧曲线同高。线条从轮拱上方绕开，露出连续米黄边。
- [ ] 副驾中门保留整面米黄。
- [ ] 没有贴到玻璃、灯、把手和密封条上。
- [ ] 两侧驾驶舱窗后各三道黑色泪滴速度纹：圆头靠车窗、尖尾朝车尾。驾驶侧图头朝左、尖尾向右；副驾侧图头朝右、尖尾向左。
- [ ] 不保留棋盘格。
- [ ] 驾驶门为暖白小剪影＋单行 World Citizen。额头用同款黑色小字标，单行居中。
- [ ] 副驾门暖白拱形 TO THE MOON / DANIEL，无色底，字间两条细线夹小菱形。
- [ ] 文字和图标是独立可编辑矢量或透明贴花，没有烘进底色。

## 材质

- [ ] 暖米黄预览起点 sRGB #E8C49A，高光下不是纯白。牛仔蓝 #174769，芥末黄 #E2A024。十六进制只是预览起点，不是膜厂色号。
- [ ] 车漆 Principled BSDF，粗糙度 0.28–0.35，Coat 权重约 0.20。
- [ ] 车衣半哑光，粗糙度 0.40–0.48，边缘干净，反光比原漆柔和，不是凸起胶条。
- [ ] 车窗有厚度、微灰，IOR 约 1.45，粗糙度 0.05–0.12，能隐约看到座椅。
- [ ] 黑色橡胶窗封和胎壁高粗糙度，不发亮。
- [ ] 前杠黑件保留塑料质感和横向格栅。灯罩清透，不是平涂白块。
- [ ] 格栅镀铬只在真实镀铬件上。尾架哑黑。脱困板保留橙色。

## 渲染与证据

- [ ] Cycles、中性灰背景、大面积柔光，额头与车盖高光受控。
- [ ] 有一张统一曝光和比例的四视图。
- [ ] 有左右前斜，以及左右车窗贴花特写。
- [ ] 至少一张前斜图证明蓝带没有窜到车盖。
- [ ] 两张正侧证明轮拱留白与泪滴方向。
- [ ] 交了可重新打开的 `.blend`（纹理已打包）、高清 PNG、关键材质参数表。
- [ ] 从新文件重新打开并复渲过。
- [ ] 报告分开写了据实拍还原的部位和只是视觉推定的部位。
- [ ] 交付说明写明：效果图不等于可直接裁切施工；施工前还要核对实车曲面和门缝。
