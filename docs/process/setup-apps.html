多 agent 协作：创建 GitHub App 与身份表

每个 agent 体系一个 GitHub App，外加一个只发 independence-gate 检查的闸门 App。一组 App 可以装到你名下任意多个仓库。

1. 填基本信息

2. 体系

同一体系的成员互相不能算独立评审。没有归入任何体系的执行者不需要 App。

3. 逐个创建 App

点按钮会在新标签页打开 GitHub 的创建页（浏览器需已登录 App 所属的账号），设置已预填，核对后点 Create GitHub App。私钥在 GitHub 上生成，不要发到聊天或仓库里。

4. 每个 App 创建后

  1. 记下 App ID；Private keys → Generate a private key。体系 App 的私钥交给对应 agent 平台；闸门 App 的私钥放进仓库 Environment（见 README）。
  2. Install App → Only select repositories → 选要用的仓库。以后加新项目，回到这里把新仓库加进去即可。

5. 身份表 .github/agent-identities.json

放进每个使用闸门的仓库。visual 段决定哪些文件算“可见改动”，按项目目录结构调整；不需要视觉验收就删掉整段。
